# Self-check: chapter 25, Reference classes

The three questions a good forecaster asks in this situation. A bad answer to any one of them is a reason to stop and fix the work before reporting.

1. **Was the reference class chosen before looking at the answer I wanted?**
   A bad answer looks like this: A class assembled to justify a plan is not an outside view.

2. **Are the unfinished and abandoned cases in the class, or only the ones that completed?**
   A bad answer looks like this: Dropping the failures produces a distribution of successes.

3. **Which percentile does the decision's loss structure call for, and did I choose it before seeing the distribution?**
   A bad answer looks like this: Quoting the median when the cost of overrun is ten times the cost of slack is choosing the wrong number.
