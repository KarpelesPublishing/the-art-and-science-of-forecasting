# Self-check: chapter 26, Decision readiness

The three questions a good forecaster asks in this situation. A bad answer to any one of them is a reason to stop and fix the work before reporting.

1. **What action does each probability range trigger, and did I write the thresholds down before the forecast arrived?**
   A bad answer looks like this: A threshold chosen after seeing the probability is a rationalisation.

2. **Is the forecast being scored, and does the score feed the next threshold?**
   A bad answer looks like this: A decision rule that never learns from its outcomes will be as wrong next year.

3. **What does being wrong cost in each direction, and does the rule reflect that asymmetry?**
   A bad answer looks like this: A symmetric rule for an asymmetric loss is the wrong rule even when the probability is right.
